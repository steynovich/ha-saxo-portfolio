# OAuth uses the Authorization Code grant for confidential clients, without PKCE

The integration authenticates with Saxo's Authorization Code grant: the token request is signed with the user's App Key and App Secret, which never leave Home Assistant. Saxo's PKCE grant is a separate grant type for apps without a secret, and its refresh requests need the original `code_verifier` instead of the secret; Saxo doesn't document combining the two. A live test on Saxo SIM (September 2026, #23) showed a Code-grant app ignores PKCE entirely: the token endpoint issued a token for a `code_verifier` that did not match the `code_challenge`. Adding PKCE would give no extra protection, so users must register their Saxo app with the **Code** grant type. See `SECURITY.md` for the full argument.
